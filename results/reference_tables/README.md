# Reference aggregate results

These CSV files are the verified aggregate values used for the paper tables:

- `colopola_classification.csv`: accuracy, sensitivity, and specificity over 30 seeds.
- `polambrimetry_overall_dice.csv`: overall Dice over 30 nested-CV runs.
- `polambrimetry_gm_wm_dice.csv`: grey- and white-matter Dice over 30 nested-CV runs.

Only aggregate statistics are included. Raw predictions, per-seed/per-specimen records, local paths, datasets, and checkpoints are excluded.
